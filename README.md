# OneStream

[![Netlify Status](https://api.netlify.com/api/v1/badges/f8b96ee7-5520-4ecd-8383-65459cb1b243/deploy-status)](https://app.netlify.com/projects/jmalalim/deploys)

**OneStream** is a modern, glassmorphism-styled music streaming web application designed for a premium audio experience. It features a seamless single-deck audio player, responsive mobile design, and a curated library of tracks.

## 🚀 Features

* **Floating Music Player:** A persistent player that follows you across the site.
* **Glassmorphism UI:** sleek, semi-transparent frosted glass aesthetic with pink & black neon gradients.
* **Responsive Design:** Fully optimized for Desktop, Tablet, and Mobile devices with a bottom navigation bar for phones.
* **Smart Audio Engine:** Reliable single-deck player with auto-play, shuffle, repeat, and queue management.
* **Media Session Support:** Control music playback directly from your device's lock screen or notification center.
* **User Library:** Like songs to save them to your personal "Liked Songs" folder.

## 🛠️ Technologies Used

* **HTML5:** Semantic structure and audio elements.
* **CSS3:** Advanced styling including Flexbox, Grid, CSS Variables, and Backdrop Filter for glass effects.
* **JavaScript (ES6+):** Core logic for audio playback, playlist management, and UI state.
* **Font Awesome:** For scalable vector icons.
* **Google Fonts:** Using 'Outfit' for modern typography.

## 📦 Installation & Setup

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/imaginemehere/Juan-Music-Player.git](https://github.com/imaginemehere/Juan-Music-Player.git)
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd Juan-Music-Player
    ```
3.  **Open `index.html` in your browser:**
    Simply double-click `index.html` or use a local server like Live Server in VS Code.

## 📱 Mobile Experience

On mobile devices, VibeStream transforms into an app-like experience:
* **Bottom Navigation:** Easy thumb-reach menu.
* **Simplified Player:** Condensed controls for play/pause and skipping.
* **Hidden Text:** Text labels are hidden for a clean, icon-first interface.
